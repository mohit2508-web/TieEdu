## Global rules (every course, no exceptions)

- **Exemplars to read first** (this is the gold standard — mirror structure exactly):
  - `backend/src/data/nineBlocks.ts` — `nineBlocks({...})`, `BlockSpec`, all block helpers
  - `backend/src/data/excelCourse/helpers.ts` — the `lesson()` builder (copy it, change only the id constants)
  - `backend/src/data/excelCourse/module1.ts` — lesson + 4-question quiz tuple pattern
  - `backend/src/data/excelCourse/index.ts` — full course config + 30-q exam bank pattern
- **Shape**: exactly 10 modules (`module1.ts` … `module10.ts`), exactly 4 lessons each = 40 lessons.
- **Every lesson**: `nineBlocks()` (objective, hook, concept[+extras], worked example, try-it, mistakes, exam angle, summary) + **4-question quiz** tuple array. Depth is the point: concepts must teach from first principles, worked examples must be real (Python code where the course is code-based), never superficial.
- **`extras`** (table/code/tip/warn/info) allowed after the concept — use them when the lesson needs a comparison table or code walkthrough. `table()` headers must be a **string array** (`['A','B']`, never `'A|B'`).
- **Template-literal safety**: lesson content sits in backtick strings — escape literal backticks as `` \` `` and write `${` as `\${` (or avoid both). Write files only with the write tool (UTF-8). Never use PowerShell string writes.
- **Unique ids**: exam bank ids are `<prefix>-bank-01` … `<prefix>-bank-30`; module ids `<prefix>-m1` … `<prefix>-m10`; lesson ids `<prefix>-m1-1` style; course id `crs-<slug>`; quiz ids are auto-generated by `lesson()`.
- **Course config**: copy the exact field set from `excelCourse/index.ts` (incl. `thumbnail_alt`, `about_course`, `prerequisites`, `audience`, `perks`, `exam_prep` with 6+ units × 3 questions, `important_questions` 6+, `previous_year_questions` 3, `exam` {15 q, 25–35 min, pass 60, distinction 85, cooldown 24, bank}, `project` {required_for_certificate: true}, `modules`). Per-course meta comes from the entry below.
- **Do NOT touch** `backend/src/data/seedCourses.ts` — the orchestrator registers courses after typecheck.
- **Verify before reporting done**: `npm run typecheck` in `backend/` must pass. Fix your own errors.
- Split per course: **Agent A** writes `helpers.ts` + `module1..module5.ts` (Part I topics), **Agent B** (after A) writes `module6..module10.ts` + `index.ts` (Part II topics + exam bank + config; may read A's files for coherence).
