1. How it works

You keep one GitHub repo for the whole class. Every task your teacher gives goes in its own folder in that repo. Pulse reads your repo, and your teacher reads your code and marks each requirement by hand. There is no AI.

c-lab-2026/            ← your one repo, for the whole class
├── PULSE.txt          ← added once: proves the repo is yours
├── task-1/  main.c    ← Task 1
├── task-2/  main.c    ← Task 2
└── task-3/  …         ← new task: you make this folder and push

Your codeThe files in the task’s folder

Requirements doneYour teacher’s marks: ✓ Done, ~ Partly or ✗ Missing
PrivateOnly you and your teachers see your page. There is no leaderboard, and you never see another student’s name, code or score.
Good habitPush small commits over several days. Your teacher sees when you worked, so one huge commit on the last night stands out.

2. Join and set up your repo (once)

  1. Open the invite email and click Join the class, or go to tieedu.in/project-pulse/join and type your class code.
  2. Sign in, or sign up, with the same email your teacher used. You see “You’re in”.
  3. On GitHub, make one public repo for the whole class, for example c-lab-2026.
  4. Open tieedu.in/project-pulse/student, paste the repo link and click Link repo.
  5. Add a file named PULSE.txt at the top of the repo containing the code Pulse shows you, then push and click Re-check my repo.

3. Do a task and see your progress

  1. A new task appears in My tasks with its folder name, for example task-3/.
  2. Put your code in that folder and push. Push as often as you like before the deadline.
  3. Your teacher reviews it. You see their marks and feedback on this page.
git add task-3
git commit -m "search by roll number"
git push
When it updatesEvery 20 minutes on its own, or right away when you press Re-check my repo.

4. Questions and fixes

ProblemWhat to do
The invite link doesn’t workSign in with the email your teacher invited. If it still fails, ask your teacher to Resend it, or join with the class code.
“Waiting for approval” after joiningYou joined with the code, so your teacher has to approve you. Tell them.
My repo shows “Not verified”Add PULSE.txt at the top of the repo with the exact code shown on your page, push, then Re-check my repo. If you still can’t, ask your teacher to check the repo with you.
Task shows “Not started” but I pushedCheck the folder name. It must be exactly the task’s folder, for example task-3/ (small letters, with the dash). Pulse shows the near-miss folder it found.
Pulse can’t read my repoThe repo must be public, and the link must point to the repo, not a single file.
Someone else linked my repoAdd your PULSE.txt and verify. The other student is unlinked and your teacher is told.
Tests say “waiting for the autograder”Only for tasks with auto-run tests: add the autograder file shown on your page, unchanged.
My page looks oldPress Re-check my repo (once every 5 minutes).
